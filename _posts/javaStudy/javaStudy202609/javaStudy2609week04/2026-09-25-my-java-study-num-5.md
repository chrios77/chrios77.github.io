```
1. 변수는 선언한 위치에 따라 뭘로 분류되는가? ⇒ 지역 변수, 멤버 변수
2. 지역 변수란? ⇒ 변수가 선언된 코드 블록을 벗어나면 사용할 수 없는, 즉, 특정 지역에서만 사용할 수 있는 변수를 말한다. 이 때 말하는 코드 블록을 스코프라고 한다.
3. 스코프라는 개념이 만들어지고 존재하게 된 이유는 무엇인가? ⇒ 비효율적인 메모리 사용과 코드 복잡성이 증가하는 것으로 인해 만들어졌다. 
4. 좋은 코드는 어떤 코드인가? ⇒ 스코프가 불필요하게 넓지 않고 군더더기가 없는 코드이다.
5. 좋은 프로그램은 어떤 프로그램인가? ⇒ 좋은 프로그램은 적절한 제약이 있는 프로그램이다. 왜냐면 무한한 자유가 있으면 무한한 에러가 발생할 가능성이 농후하다는 것을 의미하기 때문이다.
6. 형변환이란 무엇인가? ⇒ 서로 다른 타입을 둘 중 하나의 타입에 맞춰 바꾸는 것. 
7. 자동 형변환이란? ⇒ 작은 범위를 가진 타입에서 큰 범위를 가진 타입으로 타입을 바꿔 대입하는 것
8. 자동 형변환을 다른 말로 뭐라고 하는가? ⇒ 묵시적 형변환
9. 명시적 형변환이란 무엇인가? ⇒ 큰 범위에서 작은 범위로 타입을 바꿔 대입하는 것.
10. 명시적 형변환의 예시는 무엇인가? ⇒ Ex) double i = (int) doubleValue; 여기서 (int)가 명시적 형변환이다.
11. 명시적 형변환을 영어로 뭐라고 하는가? ⇒ casting
12. 변수의 값은 뭘 사용했을 때만 바뀌는 것인가? ⇒ 변수의 값은 대입 연산자를 사용했을 때만 바뀌는 것이다.
13. 오버플로우란? ⇒ 기존 타입의 범위를 초과해서 표현하면 다른 숫자가 발생하는데 이를 오버플로우라 한다.
14. 오버플로우가 발생하면 어떻게 해야 하는가? ⇒ 이는 발생하는 것만으로도 문제이므로 기존의 타입을 더 큰 범위를 가진 타입으로 바꾼다.
```
