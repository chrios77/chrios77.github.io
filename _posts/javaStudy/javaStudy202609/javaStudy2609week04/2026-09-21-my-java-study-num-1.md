<h2>26년 09월 4째주 자바 공부</h2>
<h1>26년 09월 21일 월요일 자바 공부</h1>
1. 오늘은 자바 입문 인강을 1강부터 16강까지 수강했다. 
2. 1강부터 16강까지의 내용은 주석부터 변수까지의 내용이다. 
3. 미니 프로젝트도 AI에게 주제를 물어보고 진행했다. 
4. 우선, 이번 주는 계산기 기능을 만드는 것으로 미니 프로젝트를 진행하였다.
5. 이 날 배운 내용을 AI에 입력해 퀴즈를 만들어 풀어봤다.

다음은 이 날 공부하면서 만들어 낸 내 질문들과 그에 따른 답이다.
```
1. 메인 함수란 무엇인가? ⇒ 프로그램을 시작하는 진입점(Entry Point)
2. 중괄호로 감싸는 것을 뭐라고 하는가? ⇒ 블록
3. 들여쓰기를 사용하는 이유는 무엇인가? ⇒ 코드를 쉽게 읽고 이해하기 위해.
4. 주석을 영어로 뭐라고 하는가? ⇒ comment
5. 주석에는 어떤 종류가 있고 어떤 기호를 사용하는가? ⇒ 한줄 주석 - // , 여러 줄 주석 - /* */
6. 패키지란? ⇒ 자바 파일을 분류하는 폴더
7. 변수를 사용하는 이유는? ⇒어딘가에 값을 두고 필요할 때 값을 읽을 수 있는 저장소가 필요하기 때문이다.
8. 변수를 만드는 걸 뭐라 하는가? ⇒ 변수 선언 
9. 자바에서 =는 뭘 의미하는가? ⇒ =의 오른쪽에 있는 것을 =의 왼쪽에 저장하라.
10. 변수에 처음으로 값을 대입해 저장하는 걸 뭐라고 하는가? ⇒ 변수 초기화
11. 변수에 저장되어 있는 값을 읽어서 사용하는 방법은 무엇인가? ⇒ sout + tab을 활용하여 () 안에 변수명을 입력해주면 된다.
12. 변수란? ⇒ 변하는 수
13. 변수의 값을 변경하면 어찌되는가? ⇒ 기존에 존재하던 변수의 값이 삭제되고 변경한 값이 변수에 저장된다.
```

```
1. 변수를 선언하면 컴퓨터에 무슨 일이 일어나는가? ⇒ 데이터를 보관할 수 있는 공간을 만들고, 그 곳에 이름을 부여한다.
2. 변수를 선언하면 무엇을 통해 메모리 공간에 접근이 가능한가? ⇒ 변수의 이름
3. 변수를 선언할 때 무조건 하나의 변수명만 입력할 수 있는가? 여러 개는 안되는가? → O / X ⇒ X 하나뿐 아니라 여러 개도 변수명을 입력할 수 있다. Ex) int a, b; 처럼.
4. 변수 선언과 변수 초기화는 무조건 각각 해줘야 하는가? O/X ⇒ X, 한 번에 해줘도 된다. 참고로 Ex) int a = 1, b = 2; 처럼 여러 변수를 동시에 변수 선언과 변수 초기화를 해줄 수 있다.
5. 변수는 반드시 이것을 해줘야 하는데 이것이 무엇인가? ⇒ 변수 초기화
6. 변수를 초기화하지 않고 사용하면 어떻게 되는가? ⇒ 초기화를 해주지 않은 상태에서 실행을 하면 에러가 나오거나 이상한 값이 나오게 된다. 
7. 지역 변수는 개발자가 직접 뭘 해줘야 하는가? ⇒ 변수 초기화
8. 컴파일 에러는 어떨 때 나오는 에러인가? ⇒ 자바 문법에 맞지 않았을 때 발생하는 에러이다.
9. 변수는 뭐에 따라 다양한 형식이 존재하는가? ⇒ 데이터를 다루는 종류
10. 변수 타입으로는 뭐가 존재하는가? ⇒ long, short, int, float, double, boolean, char, String이 있다. 
11. 타입을 우리나라 말로는 뭐라고 하는가? ⇒ 형식, 형
12. 문자를 나타내는 타입은 무엇이고 이를 사용 시 뭘 사용해줘야 하는가? ⇒ char/작은따옴표
13. 문자, 글자를 의미하는 것, 즉, 값을 의미하는 것을 뭐라고 하는가? ⇒ 리터널
14. 리터널은 고정된 값인가? O/X ⇒ O
15. 숫자 관련 타입으로는 뭐뭐가 있는가? ⇒ 정수로는 byte, short, int, long, 이렇게 4가지가 있고, 실수로는 float, double, 이렇게 2가지가 있다. 
16. 기타 기본 타입으로는 뭐가 있는가? ⇒ 참/거짓을 말하는 boolean, 문자 하나만 나타내는 char, 문자열을 나타내는 String이 있다. 
17. long을 사용할 때 L를 왜 사용하는가? ⇒ 20억이 넘어가는 값이라는 것을 표현하기 위해.
18. 정수는 무엇을 기본으로 사용하고 실수는 무엇을 기본으로 사용하는가? ⇒ 정수 - int, 실수 - double
19. float을 사용할 때는 무엇을 값 뒤에 붙여야 하고, float를 실무에서 사용하지 않는 이유는 무엇인가? ⇒ f가 붙어야 하고, 값이 불안정하기 때문이다.
20. 실무에서 거의 사용하지 않는 타입은 무엇인가? ⇒ byte, short, float, char.
21. 실무에서 자주 사용하는 타입은 무엇인가? int, double, boolean, String
22. 변수 이름에는 뭐뭐를 사용할 수 있나? ⇒ 영어 소문자, 영어 대문자, 숫자, 언더바 기호, 달러 기호
23. 클래스의 첫 글자는 대문자인가? O/X ⇒ O
24. 변수의 첫 글자는 대문자인가? O/X ⇒ X
25. 상수는 뭐로 구분하고 모두 소문자를 사용하는가? ⇒ 상수는 언더바 기호로 구분하고 모두 대문자로 나타낸다.
```
