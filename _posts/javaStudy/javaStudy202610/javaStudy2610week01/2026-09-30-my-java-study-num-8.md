<h1>26년 10월 1째주 Java 공부</h1>
<h2>26년 09월 30일 수요일 자바 공부</h2>
1. 오늘은 날은 자바 입문 강의 71강부터 79강까지 강의를 수강했다.
2. 강의에서 제공하는 문제 풀이를 진행했다.
3. 아직 배열/메소드 관련한 내용을 생각해내기 어려워하는 느낌이다.
4. 그래도 AI로 퀴즈를 풀어봤다.
5. 미니 프로젝트를 진행했고 조만간 진행한 프로젝트와 관련하여 회고를 해봐야겠다.

```
1. 메소드란? ⇒ 필요한 기능을 미리 정의해두고 필요할 때마다 호출해서 사용하는 것.
2. 메소드를 사용하는 이유는? ⇒ 어떤 계산이 중복될 때 일일이 찾아서 바꿔줘야 할 수 있기에 메소드를 사용하여 반복되는 일 없이 깔끔히 코드를 작성하여 활용하기 위해 사용한다.
3. 메소드를 사용하면 뭘 느낄 수 있는가? ⇒ 중복이 제거되고, 코드가 깔끔해진 것을 느낄 수 있을 것이다.
4. 메서드 정의란 무엇인가? ⇒ 메소드 선언과 메서드 본문을 작성하여 메소드를 구현하는 것.
5. 메소드는 크게 뭘로 나뉘는가? ⇒ 메소드 선언, 메소드 본문
6. 메소드 선언이란? ⇒ 이러한 메소드가 있다고 선언하는 것이고 메소드 선언 정보를 통해 다른 곳에서 해당 메소드를 호출할 수 있다.
7. 메서드 선언은 크게 뭘로 나뉘는가? ⇒ 메소드 이름, 반환 다입, 파라미터 목록
8. 파라미터는 다른 말로 뭐라고 하는가? ⇒ 매개변수
9. 파라미터는 어디에 쓰이는가? ⇒ 이 변수들은 해당 메서드 안에서만 사용된다.
10. 파라미터를 사용할 때 어떤 일이 일어나는가? ⇒ 메소드 호출을 할 때 인수를 넘기면 해당 인수가 파라미터에 대입된다.
11. 메소드 본문이란? ⇒ 메소드 본문은 메소드가 수행해야 하는 코드 블록이다.
12. 메소드를 호출할 때 뭐뭐가 맞아야 하는가? ⇒ 메소드를 호출할 때 메서드에 넘기는 값과 파라미터의 타입니 맞아야 하고 넘기는 값과 파라미터의 순서/개수도 맞아야 한다. 안 그러면 컴파일 오류가 발생한다.
13. 메소드를 호출하면 어떻게 되는가? ⇒ 메소드 본문이 순서대로 실행된다. 참고로 메소드를 호출하는 곳에서는 메소드 선언은 알지만 메소드 본문은 모른다.
14. 메소드의 실행 결과를 반환하려면 어찌해야 하는가? ⇒ return문을 사용해야 한다. 
15. 인수는 영어로 뭐라고 하고, 다른 말로 뭐라고 하는가? ⇒ 아규먼트, 인자라고도 한다.
16. 실무에서는 매개변수, 파라미터, 이 두 용어를 모두 사용하는가? O/X ⇒ O
17. 실무에서 아규먼트, 인자, 인수 라는 용어를 모두 사용하는가? ⇒ O/X ⇒ O
18. 모든 메소드는 반환값을 출력해야 하는가? O/X ⇒ O 단, 예외가 있다. 반환 타입이 void면 반환값을 생략해도 된다.
19. 반환 타입이 있으면 반드시 값을 반환해야 한는가? O/X ⇒ O, 반드시 return을 사용하여 반환값을 반환해야 한다. 
20. 메소드는 뭘 만나면 메소드에서 빠져나오는가? ⇒ 반환값이 있든 없든 return문을 만나면 메소드를 빠져나온다.
21. 반환 값 무시란? ⇒ 반환 타입이 있는 메소드를 호출했는데 만약 반환 값이 필요가 없다면 사용하지 않는 것을 말한다.
22. 자바는 항상 변수의 값을 뭘 해서 대입하는가? ⇒ 자바는 항상 변수의 값을 복사해서 대입한다. 이는 자바 대원칙 중 하나이다.
```
