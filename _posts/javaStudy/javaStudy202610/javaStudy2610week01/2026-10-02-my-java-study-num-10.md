```
1. new 연산자를 사용한다는 건 뭘 의미하는가? ⇒ new 연산자를 사용한다는 것은 메모리 상에 클래스를 토대로 참조값 형태로 제조한다는 것을 말한다.
2. 기본형 변수와 참조형 변수를 쉽게 말하면? ⇒ 기본형 변수에는 직접 사용할 수 있는 값이 들어있지만 참조형 변수에는 참조값이라는 위치가 들어가 있다. 참조형 변수를 통해서 뭔가를 하려면 결국 참조값을 통해 해당 위치로 이동해야 한다.
3. 계산에서 기본형 vs 참조형 ⇒ 기본형은 들어있는 값을 그대로 계산에 사용할 수 있고 참조형은 참조값을 그대로 사용할 수 없다. 참조형은 그저 주소지일뿐…
4. 클래스는 모두 참조형인가? O/X ⇒ O
5. 변수 대입 관련 기본형 vs 참조형 ⇒ 기본형은 변수에 값을 대입하더라도 실제 사용하는 값이 변수에 바로 들어있기에 해당 값만 복사해서 대입한다고 생각하면 쉽게 이해할 수 있다. 그런데 참조형의 경우 실제 사용하는 객체가 아니라 객체의 위치를 가르키는 참조값만 복사된다. 
6. 메소드 호출 관련 기본형 vs 참조형 ⇒ 메소드를 호출할 때 사용하는 매개변수도 결국 변수이다. 따라서 메소드를 호출할 때 매개변수에 값을 전달하는 것도 값을 복사해서 전달한다. 
7. 자바에서 메소드의 매개변수는 항상 값에 의해 전달이 되는데 이 값이 뭐냐에 따라 달라지는가? ⇒ 자바에서 메소드의 매개변수는 항상 값에 의해 전달이 되는데 값이 실제 값이나, 참조값이냐에 따라 달라진다.
8. 기본형의 메소드 호출 시 메소드는 어찌되는가? ⇒ 메소드로 기본형 데이터를 전달하면 해당 값이 복사되어 전달된다. 이 경우 메서드 내부에서 파라미터의 값을 변경해도, 호출자의 변수 값에는 영향이 없다.
9. 참조형의 메소드 호출 시 메소드는 어찌되는가? ⇒ 메서도로 참조형 데이터를 전달하면 참조값이 복사되어 전달된다. 이 경우 메소드 내부에서 파라미터로 전달된 객체의 멤버 변수를 변경하면 호출자의 객체도 변경된다.
```
