```
1. 배열이 필요한 이유가 무엇인가? ⇒ 같은 타입의 변수를 반복해서 선언하고 반복해서 사용하는 문제를 해결하기 위해 필요하다.
2. 배열이 필요하게 된 배경은 무엇인가? ⇒ 같은 타입을 가진 변수를 수백, 수천 개 선언해야 하는 경우 비슷한 변수를 반복해서 선언하는 문제가 발생하는데 이를 반복문으로 해결할 수 있을 것 같지만 변수의 이름이 다른 경우가 많기에 반복문을 적용할 수 없는 것이 대부분이기 때문에 필요하다.
3. 배열이란? ⇒ 같은 타입의 변수를 사용하기 편하게 하나로 묶어둔 것
4. 배열 변수는 어떤 식으로 선언하는가? ⇒ Ex) int[] fruits; // 배열 변수 선언 fruits = new int[5];
5. 배열을 사용하려면 뭐가 필요한가? ⇒ Ex) int fruits; 처럼 배열 변수를 선언해야 한다.
6. 배열을 사용하려면 또 뭐가 필요하고 이는 뭘 의미하는가? ⇒ fruits = new int[5]처럼 배열을 생성해야 한다. 이는 int형 변수 5개를 다룰 수 있는 배열을 새로 만든다는 뜻이다. 
7. 배열에서 숫자, boolean, String은 각각 초기화를 시킬 때 뭘로 초기화가 되는가? ⇒ 숫자는 0, boolean은 false, String은 null로 초기화된다.
8. 참조값이란? ⇒ 생성한 배열을 참조할 수 있는, 메모리의 주소를 나타내는특별한 값
9. 배열에서 인덱스란 무엇인가? ⇒ 배열의 위치를 나타내는 숫자를 말한다. 
10. 배열의 값의 위치, 즉, 인덱스는 뭐부터 시작하는가? ⇒ 0
11. 배열 값에 대입할 때 무슨 일이 일어나는가? ⇒변수에 있는 참조값을 통해서 실제 배열에 접근한다.
12. 자바의 변수 데이터 타입은 크게 보면 뭐와 뭐로 분류할 수 있는가? ⇒ 기본형/참조형
13. 기본형을 영어로 뭐라고 하는가? ⇒ Primitive Type
14. 기본형을 설명해보면 뭐라고 할 수 있는가? ⇒ 변수에 사용할 값을 직접 넣을 수 있는 데이터 타입
15. 참조형을 영어로 뭐라고 하는가? ⇒ Reference Type
16. 참조형을 설명해보면 뭐라고 할 수 있는가? ⇒ 데이터에 접근하기 위한 참조 즉, 주소를 저장하는 데이터 타입
17. 배열 같은 참조형은 뭐가 가능한가? ⇒ 크기를 동적으로 할당할 수 있다. 이렇게 배열의 크기가 변하는 걸 동적 메모리 할당이라고 한다. 
18. 참조형은 뭘하고 이로 인해 뭘 할 수 있는가?⇒ 참조형은 메모리에 저장된 배열이나 객체의 참조를 저장한다. 이로 인해 참조형은 더 복잡한 데이터 구조를 만들고 관리할 수 있다.
19. 리팩토링이란? ⇒ 기존의 코드 기능은 유지하면서 내부 구조를 개선하여 가독성을 높이고 유지보수를 용이하게 하는 과정을 말한다. 
20. 리팩토링은 왜 수행되고 어떤 도움을 주는가?⇒  리팩토링은 중복을 제거하고, 복잡성을 줄이며, 이해하기 쉬운 코드로 만들기 위해 수행된다. 또한, 버그를 줄이고, 프로그램의 성능을 향상시킬 수도 있으며, 코드의 설계를 개선하는 데에도 도움이 된다.
21. 배열의 길이는 어떤 기능을 사용하여 활용할 수 있는가? ⇒ length Ex) students.length 처럼 사용한다.
22. 배열의 초기화는 어떤 식으로 이뤄지는가? ⇒ Ex) int students = new int[]{90, 80, 70, 60, 50} // 배열 생성과 초기화
23. 배열의 초기화를 간단히 할 수 있는데 이를 어떻게 하는가? ⇒ Ex) int students = {90, 80, 70, 60, 50}.
```
