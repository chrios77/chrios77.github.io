2. 강의에서 제공해주는 문제를 풀어보았다.
3. 미니 프로젝트를 진행하려했으나 오늘은 도저히 진행하기에 힘이 들어 하지 못했다.
4. 그래도 AI를 통해 퀴즈는 풀어보았다.

```
1. 메소드를 호출할 떄도 형변환이 적용되는가? O/X ⇒ O, 매개변수에 뭔가를 대입하는 것이기 때문이다.
2. 메소드를 호출하는데 인자와 매개변수의 타입이 맞지 않다면 어찌해야 하는가? ⇒ 메소드의 인자를형변환한다. 
3. 메소드를 호출할 때 매개변수에 값을 전달하는 것도 변수에 값을 대입하는 것인가? O/X ⇒ O, 그러므로 자동 형변환이 적용된다.
4. 메소드를 호출할 때는 전달하는 인수의 타입과 매개변수의 타입이 맞아야 하는가? O/X ⇒ O, 단, 타입이 달라도 자동 형변환이 가능한 경우에는 호출할 수 있다.
5. 메소드 오버로딩이란? ⇒ 메서드명이 같고 매개변수가 다른 메소드를 여러 개 정의하는 것을 말한다.
6. 메소드 오버로딩은 언제 사용하는가? ⇒ 메소드의 이름, 반환 타입이 같아도 매개변수의 타입과 순서가 다를 때  메소드 오버로딩을 사용할 수 있다.
7. 메소드 시그니처란? ⇒ 메소드 시그니처는 자바에서 메소드를 구분할 수 있는 고유한 식별자나 서명을 말한다.
8. 메소드 시그니처는 어떻게 구성되어 있는가? ⇒ 메소드 시그니처는 메소드명, 매개변수 타입으로 구성되어 있다. 또한 매개변수 타입은 순서도 맞아야 한다.
9. 자바에서 같은 이름을 가진 메소드가 서로 다른 메소드처럼 구분되는 이유는 무엇인가? ⇒ 자바에서는 메소드 이름이 달라도 메소드 시그니처가 다르면 다른 메소드로 간주한다.
```

```
1. 클래스가 필요한 이유는 무엇인가? ⇒ 클래스가 필요한 이유는 사람은 어떤 주제에 관해 하나로 묶는 것을 좋아하기 때문에 여기 저기 흩어져 있는 내용을 하나로 묶은 것이다.
2. 클래스에 정의한 변수들을 뭐라고 하는가? ⇒ 필드 또는 멤버 변수라고 한다.
3. 멤버 변수는 왜 멤버 변수라고 하는가? ⇒ 이 변수들은 특정 클래스에 소속된 멤버이기에 이렇게 부른다.
4. 필드란? ⇒ 우선 이는 데이터 항목을 가리키는 전통적인 용어이고 DB 엑셀 등에서 데이터 각각의 항목을 필드라고 한다.
5. 자바에서 멤버 변수, 필드는 같은 뜻인가? O/X ⇒ O, 이는 클래스에 소속된 변수를 뜻한다.
6. 타입은 무엇인가? ⇒ 타입은 데이터의 종류나 형태를 나타낸다. Ex) int는 정수 타입, String은 문자 타입이다.
7. 클래스는 정확히 뭔가? ⇒ 사용자가 직접 정의하는 사용자 정의 타입을 만들 때 필요한 설계도이다.
8. 클래스를 사용해 실제 메모리에 만들어진 실체를 뭐라고 하는가? ⇒ 객체 또는 인스턴스라고 한다.
9. 클래스를 사용하면 좋은 점은 무엇인가? ⇒ 클래스를 통해 사용자가 원하는 종류의 데이터 타입을 마음껏 정의할 수 있다.
10. 객체를 만들려면 어찌해야 하는가? ⇒ 클래스를 기반으로 객체를 생성해야 한다. 그러기 위해 사용하는 것이 new 연산자이다. 이는 클래스 정보를 기반으로 새로운 객체를 생성하라는 뜻이다.
11. 객체를 생성하고 나면 자바는 뭘 하는가? ⇒ 객체를 new 연산자를 통해 생성하고 나면 자바는 메모리 어딘가에 있는 이 객체에 접근할 수 있는 참조값을 반환한다.
12. 참조값을 변수에 보관하는 이유는 무엇인가? ⇒ 객체를 생성하는 코드 자체에는 아무런 이름이 없기에 생성한 객체에 접근할 수 있는 방법이 필요하기 때문이다.
13. 클래스를 통해 생성한 객체를 사용하려면 어찌해야 하는가? ⇒ 메모리에 존재하는 객체에 접근해야 하고 이러기 위해 도트 연산자(.)를 사용하면 된다.
14. 클래스에는 뭘 정의하는가? ⇒ 클래스는 객체가 가져야할 속성인 변수와 기능인 메소드를 정의한다.
15. 배열에 참조값 대입을 어찌하는가? ⇒ Ex) Student[] students = new Student[2];
16. 변수에는 인스턴스 자체가 들어가는 것이 아니다. 그렇다면 뭐가 들어있는가? ⇒ 인스턴스의 위치를 가리키는 참조값이 들어있을 뿐이다. 그러므로 대입 시에 인스턴스가 복사되는 것이 아니라 참조값만 복사된다.
```
