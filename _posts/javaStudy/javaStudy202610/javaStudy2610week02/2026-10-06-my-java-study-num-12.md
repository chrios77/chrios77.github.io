<h1>26년 10월 2째주 Java 공부</h1>
<h2>26년 10월 06일 화요일 자바 공부</h2>
1. 오늘은 자바 기본편 강의를 25강에서 31강까지 수강했다.
2. 금일 배운 내용을 토대로 AI가 생성한 퀴즈를 풀었다.
3. 강의에서 제공하는 문제와 예제를 풀어보았다.
4. 미니 프로젝트를 진행하려했으나 오늘은 도저히 진행하기에 힘이 들어 하지 못했다.

```
1. 클래스는 데이터인 멤버 변수 뿐만 아니라 기능 역할을 하는 메서드도 포함할 수 있다? O/X ⇒ O
2. 메소드는 객체를 생성해야 호출할 수 있다? O/X ⇒ O
3. 메소드를 작성할 때 static이 붙으면 객체를 생성하지 않고도 메소드를 호출할 수 있다? O/X ⇒ O
4. 인스턴스의 메소드를 호출하는 방법은 무엇인가? ⇒ 도트 연산자를 활용하여 객체에 접근한 다음, 원하는 메소드를 호출하면 된다.
5. 클래스는 뭘 정의할 수 있는가? ⇒ 클래스는 데이터, 멤버 변수 같은 속성과 메소드 같은 기능을 정의할 수 있다.
6. 객체는 자신의 메서드를 통해 뭘 접근할 수 있는가? ⇒ 객체는 자신의 메소드를 통해 자신의 멤버 변수에 접근할 수 있다. 또한 객체의 메소드 내부에서 접근하는 멤버 변수는 객체 자신의 멤버 변수이다.
7. 캡슐화란? ⇒ OOP의 특징 중 하나로, 속성과 기능을 하나로 묶어서 필요한 기능을 메소드를 통해 외부에 제공하는 것.
8. 객체를 생성하는 시점에 어떤 작업을 하고 싶다면 뭘 이용하면 되는가? 생성자
9. 생성자가 필요한 이유가 무엇인가? ⇒ 어떤 메소드를 통해 반복을 제거했다고 치자. 이 때 어떤 객체의 멤버 변수를 사용하는 이런 경우 속성과 기능을 한곳에 두는 것이 더 나은 방법이다. 쉽게 얘기해서 어떤 객체가 자기 자신의 데이터를 변경하는 기능을 제공하는 것이 좋기 때문에 생성자를 사용한다.
10.  this란? ⇒ 객체 자신의 멤버 변수를 활용하여 객체 자신의 생성자에서 사용하는 마법의 수다. 따라서 객체 자신의 멤버 변수에 접근하려면 this를 사용하면 된다.
11.  this를 사용하는 이유는 무엇인가? ⇒ 매개변수의 이름과 멤버 변수의 이름이 같은 경우 this를 사용해서 둘을 명확하게 구분해야 하기에 this를 사용한다.
12. this는 생략할 수 있는가? O/X ⇒ O. 단, 이 경우 변수를 찾을 때 가까운 지역변수를 먼저 찾고 없으면 그 다음으로 멤버 변수를 찾는다. 멤버 변수도 없으면 오류가 발생한다.
13. 매개변수도 지역 변수인가? O/X ⇒ O
14. 생성자를 제공하는 이유는? ⇒ 프로그래밍을 하다보면 객체를 생성하고 이후에 바로 초기값을 할당해야 하는 경우가 많다. 따라서 메소드를 매번 만들어야 된다. 그래서 대부분의 OOP 언어는 객체를 생성하자 마자 즉시 필요한 기능을 좀 더 편히라게 수행할 수 있게 생성자라는 기능을 제공한다.
15. 생성자의 특징은 무엇인가? ⇒ 생성자와 메서드는 비슷하지만 약간 다른 몇 가지 특징이 있다. 첫째, 클래스 명과 똑같아야 한다. 둘째, 매개변수가 있어야 한다. 셋째, 반환 타입이 없다. 이 것들을 제외하고는 메소드와 비슷하다. 참고로 생성자는 인스턴스를 생성하고 나서 즉시 호출된다.
16. 생성자 호출은 어떻게 하는 것인가? ⇒ new 연산자를 사용하여 생성자 이음과 매개변수에 맞추어 인수를 전달하면 된다. Ex) new MemberConstruct(”user1”, 15, 90) 처럼 말이다.
17. new 키워드를 사용해서 객체를 생성할 때 ()도 포함해야 하는 이유는? ⇒ 생성자 때문이다. 객체를 생성하면 동시에 생성자를 호출한다는 의미를 포함한 것이다.
18. 생성자가 필요한 이유는? ⇒ 생성자 덕분에 객체를 생성하면서 동시에 생성 직후에 필요한 작업을 한 번에 처리할 수 있게 되어 중복 호출을 제거할 수 있었다. 또한 객체를 생성할 때 직접 정의한 생성자가 있다면 직접 정의한 생성자를 반드시 호출해야 한다는 것이다. 
19. 생성자를 메소드 오버로딩처럼 여러 개 정의할 수 있는가? O/X ⇒ O
20. 생성자를 사용하면 뭘 보장할 수 있는가? ⇒ 생성자를 사용하면 필수값 입력을 보장할 수 있다.
21. 좋은 프로그램은 어떤 프로그램인가? ⇒ 무한한 자유도가 주어지는 프로그램이 아니라 적절한 제약이 있는 프로그램이다.
```
