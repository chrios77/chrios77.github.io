```
1. 변수의 종류는 무엇이 있는가? ⇒ 멤버 변수, 지역 변수
2. 멤버 변수는 다른 말로 뭐라고 하고 어디에 선언하는가? ⇒ 멤버 변수는 다른 말로 필드라고 하고 클래스에 선언한다.
3. 지역 변수는 어디에 선언하는가? ⇒ 메소드에 선언한다.
4. 매개변수도 지역 변수의 한 종류인가? O/X ⇒ O
5. 지역 변수는 뭘 의미하는가? ⇒ 지역 변수는 특정 지역에서만 사용되는 변수라는 뜻이다.
6. 멤버 변수와 지역 변수의 값 초기화는 뭐가 다른 가? ⇒ 멤버 변수는 인스턴스를 생성할 때 자동으로 초기화되고 개발자가 초기값을 지정할 수 있다. 지역 변수는 항상 직접 수동으로 초기화해야 한다.
7. 참조형은 뭘로 기본적으로 초기화되는가? ⇒ null
8. 참조형 변수에는 항상 뭐가 들어가야 하는가? ⇒ 객체가 있는 위치를 가리키는 참조값
9. 참조형 변숭 앚직 가리키는 대상이 없거나 가리키는 대상을 나중에 입력하고 싶다면 어찌 하는가? ⇒ 참조형 변수에 null 을 넣으면 된다.
10. null은 뭘 말하는가? ⇒ 가리키는 대상이 없다. 즉, 참조할 대상이 없다는 것이다.
11. 아무도 참조하지 안는 인스턴스는 어찌되는가? ⇒ 인스턴스에 참조할 방법이 없고 메모리 용량만 차지하기 때문에 GC가 없앤다. 이 떄 JVM의 GC가 더 이상 사용하 않는 인스턴스라고 판단하고 해당 인스턴스를 자동으로 메모리에서 제거해 준다. 
12. NullPointException은 언제 발생하는가? ⇒ 참조값 없이 객체를 찾아가면 발생하는 예외이고 개발자를 가장 많이 괴롭히는 문제이다. 즉, 주소가 없는 곳을 찾아갈 때 발생하는 예외이다.
13. 객체를 참조할 때는 뭘 사용하는가? ⇒ 도트 연산자.
14. NullPointException은 주로 언제 발생한다고 보면 되는가? ⇒ 최종적으로 null값을 가지고 있는 것에 도트를 찍었을 때 발생한다. 
15. “던진다”라는 표현이 뭘 의미하는가? ⇒ 하나는 메소드 호출할 때 인수를 넣는 것, return문을 통해 반환할 값을 주는 것.
16. scanner.nextLine()은 왜 해주는가? ⇒ 입력 버퍼를 비우기 위한 코드이다.
17. 절차 지향 프로그래밍이란? ⇒ 순서를 중요하게 생각하는 방식이므로 절차를 지향하는 프로그래밍이다.
18. 객체 지향 프로그래밍이란? ⇒ 객체 지향 프로그래밍은 간단히 말하면 객체를 지향하고, 객체를 중요하게 생각하는 방식이다. 더 정확히 말하면, 실제 세계의 사물이나 사건을 객체로 보고, 이러한 객체들 간의 상호작용을 중심으로 프로그래밍하는 방식이며, 즉, “무엇을”에 중점을 둔 프로그래밍이다. 
19. 절차 지향 프로그래밍과 객체 지향 프로그래밍의 중요한 차이는? ⇒ 절차 지향은 데이터와 해당 데이터에 대한 처리 방식이 분리되어 있는 반면 객체지향에서는 데이터와 해당 데이터에 대한 행동을 하는 메서드가 하나의 객체 안에 함께 포함되어 있다.
20. 데이터 묶음이란? ⇒ 자주 사용되는 데이터들을 묶어서 멤버 변수로 사용하는 것.
21. 메서드 추출이란? ⇒ 자주 사용되거나 중복되는 기능들을 묶는 과정
22. 모듈화란? ⇒ 메서드 추출하여 메서드로 만드는 것.
23. 데이터와 해당 데이터를 사용하는 기능은 매우 밀접하게 연관되어 있다? O/X ⇒ O
24. OOP가 나오면서 데이터와 기능을 온전히 하나로 묵어서 사용할 수 있게 되었다? O/X ⇒ O
```
