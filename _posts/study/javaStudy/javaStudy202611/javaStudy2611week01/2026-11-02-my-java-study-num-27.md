```
1. 오토 박싱과 오토 언박싱이란? 오토 박싱과 오토 언박싱은 컴파일러가 개발자 대신 valueOf, xxxValue() 등의 코드를 추가해주는 기능이다. 덕분에 기본형과 래퍼형을 서로 편리하게 변환할 수 있다.
2. 오토 박싱과 오토 언박싱이 탄생한 이유는 무엇인가? ⇒ 개발자들이 오랜 기간 개발을 하다 보니 기본형을 래퍼 클래스로 변환하거나 래퍼클래스를 기본형으로 변환하는 일이 자부 발생했고, 이에 불편함을 호소했다. 자바는 이런 문제를 해결하기 위해 자바 5때부터 오토박싱과 오토 언박싱을 지원한다. 오토 박싱은 영어로 auto-boxing이라고 하고, 이는 자동으로 뭔가를 포장한다고 생각하면 된다. 오토 언박싱은 영어로 auto-unboxing이라고 한다.
3. Integer 래퍼 클래스에 정의되어 있는 메소드는 무엇인가? ⇒ valueOf() 메소드, parseInt() 메소드, compareTo() 메소드, sum() 메소드(), min() 메소드, max() 메소드 등이 있다. 이 중에서 sum() 메소드(), min() 메소드, max() 메소드는 static 메소드이고 간단한 덧셈, 작은 값, 큰 값 연산을 수행한다. 
4. Integer 래퍼 클래스의 valueOf() 메소드는 뭐하는 메소드인가? ⇒ Integer 래퍼 클래스의 valueOf() 메소드는 래퍼 타입을 반환한다. 이는 숫자, 문자열을 모두 지원한다.
5. Integer 래퍼 클래스의 parseInt() 메소드는 뭐하는 메소드인가? ⇒ Integer 래퍼 클래스의 parseInt() 메소드는 문자열을 기본형으로 변환한다.
6. Integer 래퍼 클래스의 compareTo() 메소드는 뭐하는 메소드인가? ⇒ Integer 래퍼 클래스의 compareTo() 메소드는 내 값과 인수로 넘어온 값을 비교한다. 내값이 크면 1, 같으면 0, 내 값이 작으면 -1을 반환한다. 
7. 그렇다면 Integer 래퍼 클래스의 valueOf() 메소드를 사용하여야 하는가 아니면 Integer 래퍼 클래스의 parseInt() 메소드를 사용해야 하는가? ⇒ 원하는 타입에 맞는 메서드를 사용하면 된다. 예를 들어 valueOf(”10”)는 래퍼타입을 반환하고 parseInt(”10”)는 기본형을 반환한다. 참고로 Long.parseLong()처럼 각 타입에 parseXxx()가 존재한다.
8. 래퍼 클래스는 객체이기에 기본형보다 다양한 기능을 제공한다. 그렇다면 더 좋은 래퍼 클래스만 제공하면 되지 기본형을 제공하는 이유는 무엇인가? ⇒ 계산 결과는 시스템마다 다르지만 기본형 연산이 래퍼 클래스보다 대략 5배 정도 빠르다. 기본형은 메모리에서 단순히 해당 크기 만큼의 공간을 차지하는데 예를 들어, int는 보통 4바이트의 메모리를 사용한다. 래퍼 클래스의 인스턴스는 내부에 필드로 가지고 있는 기본형의 값 뿐만 아니라 자바에서 객체 자체를 다루는데 필요한 객체 메타데이터를 포함하므로 더 많은 메모리를 사용한다. 참고로 자바 버전과 시스템마다 다르지만 대략 8에서 16 바이트의 메모리를 추가로 사용한다.
9. 기본형과 래퍼 클래스 둘 중 어떤 것을 사용해야 할까? ⇒ 예를 들어, 10억 번의 연산을 수행했을 때 0.3초와 1.5초의 차이다. 기본형이든 래퍼 클래스든 이것을 1회로 환산하면 둘 다 매우 빠르게 연산이 수행된다. 일반적인 애플리케이션을 만드는 관점에서 보면 이런 부분을 최적화해도 사막의 모래알 하나 정도의 차이가 날 뿐이다. CPU 연산을 아주 많이 수행하는 특수한 경우이거나, 수만에서 수십만 이상 연속해서 연산을 수행해야 하는 경우라면 기본형을 사용해서 최적화를 고려하자. 그렇지 않은 일반적인 경우라면 코드를 유지보수하기 더 나은 것을 선택하면 된다.
10. 유지보수 vs 최적화 ⇒ 유지보수나 최적화를 고려해야 하는 상황이라면 유지보수하기 좋은 코드를 먼저 고민해야 한다. 특히 최신 컴퓨터는 매우 빠르기에 메소리 상에서 발생하는 연산을 몇 번 줄인다고 해도 실질적인 도움이 되지 않는 경우가 많다. 코드 변경 없이 성능 최적화를 하면 가장 좋겠지만, 성능 최적화는 대부분 단숨함보다는 복잡함을 요구하고, 더 많은 코드들을 추가로 만들어야 한다. 최적화를 위해 유지보수 해야 하는 코드가 더 늘어나는 것이다. 그런데 진짜 문제는 최적화를 한다고 했지만 전체 애플리케이션의 성능 관점에서 보면 불필요한 최적화를 할 가능성이 있다. 특히 웹 애플리케이션의 경우 메모리 안에서 발생하는 연산 하나보다 네트워크 호출 한 번이 많게는 수십만배 더 오래 걸린다. 자바 메모리 내부에서 발생하는 연산을 수천번에서 한 번으로 줄이는 것보다, 네트워크 호출을 한 번을 더 줄이는 것이 더 효과적인 경우가 많다. 권장하는 방법은 개발 이후에 성능 테스트를 해보고 정말 문제가 되는 부분을 찾아서 최적화 하는 것이다.
11. Class 클래스란? ⇒ 자바에서 Class 클래스는 클래스의 정보 즉, 메타데이터를 다루는데 사용된다. Class 클래스를 통해 개발자는 실행 중인 자바 애플리케이션 내에서ㅏ 필요한 클래스의 속성과 메소드에 대한 정보를 조회하고 조작할 수 있다.
12. Class 클래스의 주요 기능은 무엇인가? ⇒ Class 클래스의 주요 기능은 타입 정보 얻기, 리플렉션, 동적 로딩과 생성, 애노테이션 처리가 있다. 타입 정보 얻기는 클래스의 이름, 슈퍼 클래스, 인터페이스, 접근 제한자 등과 같은 정보를 조회할 수 있다. 리플렉션은 클래스에 정의된 메소드, 필드, 생성자 등을 조회하고, 이들을 통해 객체 인스턴스를 생성하거나 메소드를 호출하는 등의 작업을 할 수 있다. 동적 로딩과 생성은 Class.forName(() 메소드를 사용하여 클래스를 동적으로 로드하고, newInstatnce() 메소드를 통해 새로운 인스턴스를 생성할 수 있다. 애노테이션 처리는 클래스에 적용된 애노테이션을 조회하고 처리하는 기능을 제공한다. 최종적으로 예를 들어, String.class는 String 클래스에 대한 Class 객체를 나타내고, 이를 통해 String 클래스에 대한 메타데이터를 조회하거나 조작할 수 있다.
13. clazz란? ⇒ class는 자바의 예약어이기에 패키지명이나 변수명으로 사용할 수 없다. 그러므로 자바 개발자들은 class 대신 clazz라는 이름을 관행으로 사용한다. clazz는 class와 유사하게 들리고, 이 단어가 class를 의미한다는 것을 쉽게 알 수 있다. 주의할 것은 main() 메소드 옆에 throws Exception이 추가된 부분에 주의하자. 이 코드가 없으면 컴파일 오류가 발생한다.
14. Class 클래스는 어떻게 조회할 수 있는가? ⇒ Class 클래스는 3가지 방법으로 조회할 수 있다. 예를 들어, Class clazz = String.class; 처럼 해서 클래스에서 조회할 수도 있고, Class clazz = new String().getClass(); 처럼 인스턴스에서 조회할 수도 있으며, Class clazz = Class.forName(”java.lang.String”); 처럼 문자열로 조회할 수 있다.
15. Class 클래스의 주요 기능은 무엇인가? ⇒ Class 클래스의 주요 기능은 getDeclaredFields() 메소드, getDeclaredMethods() 메소드, getSuperclass() 메소드, getInterfaces() 메소드가 있다. getDeclaredFields() 메소드는 클래스의 모든 필드를 조회한다. getDeclaredMethods() 메소드는 클래스의 모든 메소드를 조회한다. getSuperclass() 메소드는 클래스의 부모 클래스를 조회한다. getInterfaces() 메소드는 클래스의 인터페이스들을 조회한다.
16. 클래스 생성하기는 어찌하는가? ⇒ Class 클래스에는 클래스의 모든 정보가 들어있다. 이 정보를 기반으로 인스턴스를 생성하거나, 메소드를 호출하고, 필드의 값도 변경할 수 있다.
17. getDeclaredConstructor().newInstance()를 하면 어찌되는가? ⇒ getDeclaredConstructor().newInstance()를 하면 getDeclaredConstructor()는 생성자를 선택하고 newInstance()를 하면 선택된 생성자를 기반으로 인스턴스를 생성한다.
18. 리플렉션이란? ⇒ 리플렉션은 영어로 reflection이라고 하고, Class를 사용하면 클래스의 메타 정보를 기반으로 클래스에 정의된 메소드, 필드, 생성자 등을 조회하고, 이들을 통해 객체 인스턴스를 생성하거나 메소드를 호출하는 작업을 할 수 있다. 이런 작업을 리플렉션이라고 한다. 추가로 애노테이션 정보를 읽어서 특별한 기능을 수행할 수도 있다. 최신 프레임워크들은 이런 기능을 적극 활용한다.
19. System 클래스는 무엇을 제공하는가? ⇒ System 클래스는 시스템과 관련된 기본 기능들을 제공한다. System 클래스는 표준 입력, 표준 출력, 오류 스트림, 시간 측정, 환경 변수, 시스템 속성, 시스템 종료, 배열 고속 복사를 제공한다.
20. System 클래스에서 제공하는 표준 입력, 표준 출력, 오류 스트림 기능은 무엇인가? ⇒ System 클래스에서 제공하는 표준 입력, 표준 출력, 오류 스트림 기능으로 System.in, System.out, System.err를 제공하는데 각각 표준 입력, 표준 출력, 오류 스트림을 말한다.
21. System 클래스에서 제공하는 시간 측정 기능으로 무엇을 제공하는가? ⇒ System 클래스에서 제공하는 시간 측정 기능으로는 System.currentTimeMills()와 System.nanoTime()을 제공하는데 이는 현재 시간을 밀리초 또는 나노초 단위로 제공하는 것이다.
22. System 클래스에서 제공하는 환경 변수 기능으로 무엇을 제공하는가? ⇒ System 클래스에서 제공하는 환경 변수 기능으로는 System.getenv() 메소드를 사용하여 OS에서 설정한 환경 변수의 값을 얻을 수 있다.
23. System 클래스에서 제공하는 시스템 속성 기능으로 뭘 제공하는가? ⇒ System 클래스에서 제공하는 시스템 속성 기능으로 System.getProperties()를 사용해 현재 시스템 속성을 얻거나 System.getProperties(String key)로 특정 속성을 얻을 수 있다. 시스템 속성은 자바에서 사용하는 설정값이다.
24. System 클래스에서 제공하는 시스템 종료 기능으로 무엇을 제공하는가? ⇒ System 클래스에서 제공하는 시스템 종료 기능으로 System.exit(int status) 메소드를 제공하는데 System.exit(int status) 메소드는 프로그램을 종료하고, OS에 프로그램 종료의 상태 코드를 전달한다. 상태 코드가 0이면 정상 종료를 하고, 상태 코드가 0이 아니면 오류나 예외적인 종료를 일으킨다.
25. System 클래스에서 제공하는 배열 고속 복사 기능으로는 무엇이 있는가? ⇒ System 클래스에서 제공하는 배열 고속 복사 기능으로 System.arraycopy 메소드를 제공하는데, 이는 시스템 레벨에서 최적화된 메모리 복사 연산을 사용한다. 이는 직접 반복문을 사용해서 배열을 복사할 때보다 수 배 이상 빠른 성능을 제공한다.
26. System 클래스를 사용할 때 참고사항은 무엇인가? ⇒ System.exit(0)는 웬만해서는 사용하면 안된다. 프로그램을 끝낼 때는 뒷정리를 하고 끝내야 하기 때문이고 의도와는 상관없이 종료되기 때문이다. 확실하게 프로그램의 뒷정리를 끝냈다면 사용하면 된다.
27. Math 클래스란 무엇인가? ⇒ Math 클래스는 수 많은 수학적 문제를 해결해주는 클래스이다. 이 클래스는 너무 많은 기능을 제공하기에 실제로 필요할 때 검색하거나 API 문서를 찾아보는 것이 좋다.
28. Math 클래스에서 제공하는 메소드는 무엇이 있는가? ⇒ 기본 연산 메소드, 지수/로그 연산 메소드, 반올림/정밀도 메소드, 삼각 함수 메소드, 기타 유용한 메소드가 있다.
29. Math 클래스에서 제공하는 기본 연산 메소드로는 무엇이 있는가? ⇒ Math 클래스에서 제공하는 기본 연산 메소드로는 abs(x) 메소드, max(a, b) 메소드, max(a, b) 메소드가 있다. abs(x) 메소드는 절댓값을 구하는 메소드이다. max(a, b) 메소드는 최댓값, max(a, b) 메소드는 최솟값을 제공하는 메소드이다.
30. Math 클래스에서 제공하는 지수/로그 연산 메소드는 무엇이 있는가? ⇒ Math 클래스에서 제공하는 지수/로그 연산 메소드는 exp(x) 메소드, log(x)  메소드, log10(x) 메소드, pow(a, b) 메소드가 있다. exp(x) 메소드는 e^x 계산을 수행한다. log(x)  메소드는 자연로그, log10(x) 메소드는 로그 10 계산을 수행한다. pow(a, b) 메소드는 a의 b 제곱 계산을 수행한다.
31. Math 클래스에서 제공하는 반올림/정밀도 메소드는 무엇이 있는가? ⇒ Math 클래스에서 제공하는 반올림/정밀도 메소드는 ceil(x) 메소드, floor(x) 메소드, rint(x) 메소드, round(x) 메소드가 있다. ceil(x) 메소드는 올림 계산, floor(x) 메소드는 내임 계산, round(x) 메소드는 반올림 계산을 수행한다. rint(x) 메소드는 가장 가까운 정수로 반올림 계산을 실시한다.
32. Math 클래스에서 제공하는 삼각 함수 메소드는 무엇이 있는가? ⇒ Math 클래스에서 제공하는 삼각 함수 메소드는 sin(x) 메소드, cos(x) 메소드, tan(x) 메소드가 있다. sin(x) 메소드는 사인 연산, cos(x) 메소드는 코사인 연산, tan(x) 메소드는 탄젠트 연산을 수행한다.
33. Math 클래스에서 제공하는 기타 유용한 메소드로는 무엇이 있는가? ⇒ Math 클래스에서 제공하는 기타 유용한 메소드로는 제곱근 계산을 수행하는 sqrt(x) 메소드, 세제곱근 계산을 수행하는 cbrt(x) 메소드, 0.0과 1.0 사이의 무작위 값을 생성하는 random() 메소드가 있다.
34. Random 클래스란? ⇒ 난수 계산을 할 때 Math.random() 메소드를 사용해도 되지만 Random 클래스를 사용하면 더욱 다양한 랜덤값을 구할 수 있다. 참고로 Math.random() 메소드도 내부에서는 Random 클래스를 사용한다. 또한 Random 클래스는 java.util 패키지에 속해 있다.
35. Random 클래스에서 제공하는 메소드로는 뭐가 있는가? ⇒ Random 클래스에서 제공하는 메소드로는 nextInt() 메소드, nextDouble() 메소드, nextBoolean()가 있다. 이것들은 각각 랜덤으로 정수값이, 실수값이, 논리값이 나온다.
36. Random 클래스에서 제공하는 메소드에 범위를 줄 수도 있는가? O/X ⇒ O. Ex) random.nextInt(10); 이라고 하면 0부터 9까지의 10 미만 정수값을 랜덤으로 생성한다. 만약 1부터 10까지의 난수를 생성하고 싶다면 random.nectInt(10) + 1; 처럼 해주면 된다. 참고로 이를 화면에 출력하려면 System.out.println 메소드를 사용해야 한다.
37. 씨드란 무엇인가? ⇒ 씨드는 영어로 seed라고 하고, 랜덤은 내부에서 씨드값을 사용해서 랜덤 값을 구한다. 그런데 씨드값이 같으면 항상 같은 결과가 출력된다. 예를 들어 Random random = new Random(1);이라고 했을 때 1이라는 씨드값이, 즉, 처음값이 같으면 Random의 결과가 같다. 여기서 씨드값은 1을 말한다.
38. 만약 Random random = new Random()처럼 씨드 위치를 비워두면 어찌되는가? ⇒ Random random = new Random()처럼 씨드 위치를 비워 생성자를 비워두면 내부에서 System.nanoTime()에 여러가지 복잡한 알고리즘을 섞어서 씨드값을 생성한다. 따라서 반복 실행해도 결과가 항상 달라진다.
39. 만약 Random random = new Random(int seed)처럼 씨드 위치에 직접 값을 전달하면 어찌되는가? ⇒ Random random = new Random(int seed)처럼 씨드 위치에 직접 값을 전달할 수 있는데 씨드값이 같으면 여러 번 반복 실행해도 실행 결과가 같다. 이렇게 씨드 값을 직접 사용하면 결과 값이 항상 같기에 결과가 달라지는 핸덤 값을 구할 수 없다. 그러나 결과가 고정되기에 테스트 코드 같은 곳에서 같은 결과를 검증할 수 있다. 참고로 마인크래프트 같은 게임은 게임을 시작할 때 지형을 핸덤으로 생성하는데, 같은 씨드값을 설정하면 같은 지형을 생성할 수 있다.
```
