```
1. 메소드에 static을 붙이면 뭘 만들 수 있는가? ⇒ 정적 메소드
2. 정적 메소드는 뭘 할 수 있는가? ⇒ 정적 메소드는 정적 변수처럼 인스턴스 생성없이 클래스 명을 통해서 바로 호출할 수 있다.
3. static이 붙은 정적 메소드는 뭘할 수 있는가? ⇒ static이 붙은 정적 메소드는 객체 생성 없이 클래스명 + . + 메소드명으로 바로 호출할 수 있다.
4. 정적 메소드 덕분에 뭘 할 수 있는가? ⇒ 정적 메소드 덕분에 불필요한 객체 생성없이 편리하게 메소드를 사용할 수 있다.
5. 클래스 메소드란? ⇒ 메소드 앞에도 static을 붙일 수 있는데 이것을 정적 메소드 혹은 클래스 메소드라고 한다.
6. static이 붙은 메소드를 정적 메소드 이름 붙인 이유는? ⇒ static이 정적이라는 뜻이기 때문이다.
7. static이 붙은 메소드를  클래스 메소드라고 이름 붙인 이유는? ⇒ 인스턴스 생성 없이 마치 클래스에 있는 메소드를 바로 호출하는 것처러머 느껴지기 때문이다.
8. 인스턴스 메소드란? ⇒ static이 붙지 않은 메소드는 인스턴스를 생성해야 호출할 수 있는데 이를 인스턴스 메소드라고 한다.
9. 정적 메소드의 장점은 무엇인가? ⇒ 정적 메소드는 객체 생성없이 클래스에 있는 메소드를 바로 호출할 수 있다는 장점이 있다. 그러나 정적 메소드는 언제나 사용할 수 있는 것이 아니다.
10. 정적 메소드 사용법에 대해 설명해 봐라 ⇒ static 메소드는 static만 사용할 수 있다. 즉, 클래스 내부의 기능을 사용할 때, 정적 메소드는 static이 붙은 정적 메소드나 정적 변수만 사용할 수 있고, 인스턴스 변수나 인스턴스 메소드를 사용할 수 없다. 반대로 모든 곳에서 static을 호출할 수 있는데 정적 메소드는 공용이 가능하기에 접근 제어자만 허락한다면 클래스를 통해 모든 곳에소  static을 호출할 수 있다.
11. 정적 메소드가 static이 없는 인스턴스 변수나 인스턴스 메소드에 접근하면 어찌되는가? ⇒ 정적 메소드는 static만 사용할 수 있기에 정적 변수, 정적 메소드에는 접근할 수 있지만 static이 없는 인스턴스 변수나 인스턴스 메소드에 접근하면 컴파일 오류가 발생한다.
12. 인스턴스 메소드는 정적 메소드에 접근할 수 있는데 그 이유가 무엇인가? ⇒ 인스턴스 메소드는 모든 곳에서 stataic을 호출할 수 있기에 정적 변수, 정적 메소드에 접근할 수 있고, 물론 인스턴스 변수, 인스턴스 메소드에도 접근할 수 있다.
13. 정적 메소드가 인스턴스의 기능을 사용할 수 없는 이유가 무엇인가? ⇒ 정적 메소드는 클래스의 이름을 통해 바로 호출할 수 있기에 인스턴스처럼 참조값의 개념이 없다. 특정 인스턴스의 기능을 사용하려면 참조값을 알아야 하는데 정적 메소드는 참조값 없이 호출한다. 따라서 정적 메소드 내부에서 인스턴스 변수나 인스턴스 메소드를 사용할 수 없다.
14. 정적 메소드를 객체의 참조값에 직접 메개변수로 전달할 수 있는가? ⇒ 객체의 참조값을 직접 메개변수로 전달하면 정적 메소드도 인스턴스 변수나 메소드를 호출할 수 있다.
15. 멤버 메소드의 종류로는 뭐가 있는가? ⇒ 인스턴스 메소드, 클래스 메소드
16. 인스턴스 메소드 무엇인가란? ⇒ static이 붙지 않은 멤버 메소드
17. 클래스 메소드란 무엇인가? ⇒ static이 붙은 멤버 메소드, 클래스 메소드, 정적 메소드, static 메소드 등으로 부른다. 
18. static import는 무엇인가? ⇒ 특정 클래스의 정적 메소드나 정적 변수를 적용하여 활용할 때 사용하는 것.
19. 정적 메소드의 대표적인 예시가 무엇인가? ⇒ main() 메소드
20. 메인 메소드에 대해 설명해보라. ⇒ main() 메소드는 프로그램을 시작하는 시작점이 되는데, 생각해보면 객체를 생성하지 않아도 main() 메소드가 작동했다. 이것은 main() 메소드가 static이기 때문이다.
21. 메인 메소드에 대해 더 설명해봐라. ⇒ 정적 메소드는 정적 메소드만 호출할 수 있다. 따라서 정적 메소드인 main()이 호출하는 메소드에는 정적 메소드를 사용했다. 더 정확히 말하자면 정적 메소드는 같은 클래스 내부에서 정적 메소드만 호출할 수 있기에 정적 메소드인 main() 메소드가 같은 클래스에서 호출하는 메소드도 정적 메소드로 선언해서 사용했다.
22. final 키워드란? ⇒ final 키워드는 이름 그대로 끝이라는 뜻으로, 지역 변수에 주로 사용하며 이 키워드가 붙으면 더는 값을 변경할 수 없다. 참고로 final은 class, method를 포함한 여러 곳에 붙을 수 있다.
23. final은 최초 한 번만 할당 가능한가? O/X ⇒ O
24. final은 매개변수에도 넣을 수 있는가? O/X ⇒ O, 단 매개변수의 값을 중간에 바꿀 수가 없다.
25. final을 필드에 사용하게 되면 어찌되는가? ⇒ 생성자를 활용해서 값을 넣어줘야 하고 이후에는 값을 바꿀 수 없다.
26. static final이 필드에 붙으면어찌되는가? ⇒ 필드명을 대문자로 다 써줘야 하고, 이를 상수라고 부른다.
27. 생성자를 통해서 final 필드를 초기화하는 경우 어찌되는가? ⇒ 생성자를 통해서 final 필드를 초기화하는 경우, 각 인스턴스마다 final 필드에 다른 값을 할당할 수 있다. 물론 final을 사용했기에 생성 이후에 이 값을 변경하는 것은 불가능하다.
28. final 필드를 필드에서 초기화는 경우, 모든 인스턴스가 같은 값을 가진다. 왜냐하면 필드 초기화는 필드의 코드에 해당 값이 개발자에 의해 미리 정해져 있기 때문이다. 이렇게 되면 모든 인스턴스가 같은 값을 사용하기에 결과적으로 메모리를 낭비하게 된다. 또한 같은 값이 계속 생성되는 것은 개발자가 보기에 중복이기에 이럴 때 사용하면 좋은 것이 바로 static 영역이다.
```
