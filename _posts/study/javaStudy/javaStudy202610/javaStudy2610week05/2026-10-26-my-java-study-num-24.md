```
1. 사이드 이펙트의 근본적인 원인은 무엇인가? ⇒ 사이드 이펙트 문제를 생각해보면 공유하면 안된느 객체를 여러 변수에서 공유했기에 발생한 문제이다. 일단 객체의 공유를 막을 수 있는 방법은 없다. 사이드 이펙트의 더 근본적인 원인을 고려해보면 객체를 공유하는 것 자체는 문제가 아니다. 객체를 공유한다고 바로 사이드 이펙트가 발생하지는 않는다. 문제의 직접적인 원인은 공유된 객체의 값을 변경한 것에 있다.
2. 불변 객체란? ⇒ 객체 내부의 값, 필드, 멤버 변수 같은 객체의 상태가 변하지 않는 객체를 불변 객체, 영어로 Immutable Object라고 한다.
3. 불변 객체를 만드는 방법은 무엇인가? ⇒ final를 잘 활용하는 것이다. 그리고 어떻게든 필드 값을 변경할 수 없게 클래스를 설계하면 된다. 
4. 불변이라는 단순한 제약을 사용해서 사이드 이펙트를 막을 수 있는가? O/X ⇒ O, 객체의 공유 참조는 막을 수 없다. 그래서 객체의 값을 변경하면 다른 곳에서 참조하는 변수의 값도 함께 변경되는 사이드 이펙트가 발생한다. 사이드 이펙트가 발생하면 안되는 상황이라면 불변 객체를 만들어서 사용하면 된다. 불변 객체는 값을 변경할 수 없기에 사이드 이펙트가 원천 차단된다.
5. 불변 객체는 값을 변경할 수 있는가? O/X ⇒ X, 불변 객체는 값을 변경할 수 없다. 따라서 불변 객체의 값을 변경하고 싶다면 변경하고 싶은 값으로 새로운 불변 객체를 생성해야 한다. 이렇게 하면 기존 변수들이 참조하는 값에는 영향을 주지 않는다.
6. 가변 객체와 불변 객체란 무엇인가? ⇒ 가변 객체는 Mutable, 불변 객체는 Immutable이라고 한다. 가변은 처음 만든 이후 상태가 변할 수 있다는 뜻이고 불변은 처음 만든 이후 상태가 변하지 않는다는 뜻이다.
7. Address 클래스와 ImmutableAddress 클래스란 무엇인가? ⇒ Address 클래스는 가변 클래스이다. 이 클래스로 객체를 생성하면 가변 객체가 된다. ImmutableAddress 클래스는 불변 클래스이다. 이 클래스로 객체를 생성하면 불변 객체가 된다. 
8. 불변 객체를 사용함에도 불구하고 값을 바꿔야 한다면 어찌해야 하는가? ⇒ 불변 객체는 기존 값은 변경하지 않고 대신 계산 결과를 바탕으로 새로운 객체를 만들어서 반환한다. 이렇게 하면 불변도 유지하면서 새로운 결과도 만들 수 있다. 불변 객체에서 변경과 관련된 메소드들은 보통 객체를 새로 만들어서 반환하기에 꼭 반환값을 받아야 한다.
9. 불변 객체에서 값을 변경하는 경우 뭘로 시작하는 경우가 많은가? ⇒ withXxx() 형태를 띈다. 불변 객체에서 값을 변경하는 경우 with로 시작하는 경우가 많다. 이는 관례처럼 사용되는데, 원본 객체의 상태가 그대로 유지됨을 강조하면서 변경사항을 새 복사본에 포함하는 과정을 간결하게 표현한 것이다. 
10. 자바에서 문자를 다루는 대표적인 타입은 무엇인가? ⇒ char, String
11. char 타입은 뭘하는가? ⇒ char 타입은 문자 하나를 담아서 출력하는 것이다. 
12. String로 객체를 생성하는 방법은 무엇인가? ⇒ String 클래스로 객체를 생성하는 방법은 “hello”처럼 쌍따옴표를 사용하던가, 아니면 new String(”hello”)처럼 객체를 생성하는 것이다.
13. String 타입은 무엇인가? ⇒ String 타입은 일단 클래스이기에 참조형이다. 따라서 변수에는 String 인스턴스의 참조값만 들어갈 수 있다. 문자열은 매우 자주 사용된다. 그래서 편의상 쌍따옴표로 문자열을 감싸면 자바에서 new String(”hello”)처럼 변경해준다.
14. String 클래스의 구조는 어찌되는가? ⇒ String 클래스의 구조는 여기에 적어두기는 길어서 String 클래스의 구조는 알아서 확인해보자.
15. String 클래스의 필드는 어찌되어 있는가? ⇒ String 클래스의 필드에는 private final char[] var;이라고 되어 있다. 여기에는 String의 실제 문자열 값이 보관된다. 문자 데이터 자체는 char[]에 보관된다. String 클래스는 개발자가 직접 다루기 불변한 char[]을 내부에 감추고 String 클래스를 사용하는 개발자가 편리하게 문자열을 다룰 수 있도록 다양한 기능을 제공한다. 그리고 메소드 제공을 넘어 자바 언어 차원에서도 여러 편의 문법을 제공한다.
16. 자바 9이후 String 클래스의 변경 사항은 무엇인가? ⇒ 자바 9부터 String 클래스에서 char[] 대신 byte[]를 사용한다. 예를 들어, private final byte[] value처럼 말이다. 
17. String 클래스의 메소드는 어찌되어 있는가? ⇒ String 클래스에서 제공하는 메소드는 되게 많다. 이 중에서 주요 메소드는 length() 메소드, charAt(int index) 메소드, substring(int beginIndex, int endIndex)메소드, indexOf(String str) 메소드, toLowerCase() 메소드, toUpperCase() 메소드, trim() 메소드, concat(String str) 메소드가 있다. 기능이 방대하므로 필요한 기능이 있으면 검색하거나 API문서를 찾아보자.
18. length() 메소드는 뭘 하는 메소드인가? ⇒ length() 메소드는 문자열의 길이를 반환한다.
19. charAt(int index) 메소드는 뭘 하는 메소드인가? ⇒ charAt(int index) 메소드는 특정 인덱스의 문자를 반환한다.
20. substring(int beginIndex, int endIndex)메소드는 뭘 하는 메소드인가? ⇒ substring(int beginIndex, int endIndex)메소드는문자열의 부분 문자열을 반환한다.
21. indexOf(String str) 메소드는 뭘 하는 메소드인가? ⇒ indexOf(String str) 메소드는 특정 문자열이 시작되는 인덱스를 반환한다.
22. toLowerCase() 메소드는 뭘 하는 메소드인가? ⇒ toLowerCase() 메소드는 문자열을 소문자로 변환한다.
23. toUpperCase() 메소드는 뭘 하는 메소드인가? ⇒ toUpperCase() 메소드는 문자열을 대문자로 변환한다.
24. trim() 메소드는 뭘 하는 메소드인가? ⇒ trim() 메소드는 문자열 양 끝의 공백을 제거한다.  
25. concat(String str) 메소드는 뭘 하는 메소드인가? ⇒ concat(String str) 메소드는 문자열을 더한다.
26. String 클래스는 참조형인가? O/X ⇒ O, String은 클래스이다. 그래서 기본형이 아니라 참조형이다. 참조형은 변수에 계산할 수 있는 값이 들어있는 것이 아니라 x001과 같은 계산할 수 없는 참조값이 들어있다. 그러므로 원칙적으로 + 같은 연산을 사용할 수 없다.
27.  자바에서 문자열을 더할 때는 무엇을 사용해야 하는가? ⇒  자바에서 문자열을 더할 때는 String 클래스에서 제공하는 concat() 같은 메소드를 사용해야 한다. 하지만 문자열은 너무 자주 다루어지기에 자바에서 편의상 특별히 + 연산을 제공한다.
```
